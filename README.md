# On My Way

A small HTML/CSS/JavaScript prototype for a computational thinking assignment.

## A cinematic soundtrack

The user describes a walking POV in natural language. On My Way uses simple, predictable keyword rules to transform that original description into a cinematic city scene and a fictional simulated soundtrack.

- **Rainy night / rebellious:** neon rain, cinematic noir, Midnight Velocity — The Static Hearts.
- **Autumn / coming of age:** warm light and falling leaves, Golden Hour Rush — Sunday Avenue.
- **Custom POV:** a neutral cinematic fallback.

## Computational thinking

- **Representation:** original POV text is retained alongside a simplified context and atmosphere.
- **State:** POV, active scene, current track, and play/pause state change the interface.
- **Interaction:** the user writes, speaks, or selects a POV, then can reveal Behind the Scene to inspect the rule-based transformation.

Open index.html in a modern browser. No build process, framework, external API, or backend is required.
